# Source notes

Store human-readable source capture notes here. Raw measurements belong in `data/raw/` and must retain structured provenance.

`OPEN_LEDGER_HUNT.md` is the publication decision and the next public-ledger hunt. It
does not admit new scored evidence.

`registry.yaml` is machine validated. `captures/` contains compact, manually
reviewed fact snapshots rather than copied webpages. Artifact checksums make later
source or transcription changes explicit.
