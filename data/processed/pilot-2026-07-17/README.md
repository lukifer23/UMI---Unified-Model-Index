# Reproducible pilot outputs

Generated from `data/raw`, `config`, and `data/sources/registry.yaml` with UMI v0.2.1.
`partial_scores` is diagnostic only: every `rank` and `headline_overall` is null.
It includes v0.2.1 hierarchical coverage, readiness, confidence, deployment/version,
and complete/scored fingerprint fields. `references.json` and `references.csv` contain
the stable long-form external-index and attempted-task-cost observations.
