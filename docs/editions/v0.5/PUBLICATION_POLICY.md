# UMI Public v0.5 publication policy

Allowed states:

- `experimental_point_score`
- `provisional_public_score`
- `certified_public_score`
- `insufficient_common_support`
- `identity_unresolved`
- `source_concentration_failed`
- `uncertainty_incomplete`
- `diagnostic_only`
- `rejected`

v0.5 current state: **`provisional_public_score`**.

A `certified_public_score` requires the full precommitted construct, identity, source
concentration ≤ 0.35 on every component with no exemption, frozen anchors, uncertainty,
rank stability, reproducible artifacts, and documentation that matches the artifacts.

This edition fails certification because:

1. Operational Efficiency is 100% DataCurve.
2. Access Economics is 100% WeirdML source-reported cost.
3. Context reliability, language/instruction, interactive latency, agentic cost, and
   tariff baskets have no admissible common-core series.
4. DeepSWE tokens/steps and WeirdML cost are not success-adjusted.

Do not describe v0.5 as a certified governed headline. Do not treat v0.4 ranks as
statistically established.
