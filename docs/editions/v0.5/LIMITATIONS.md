# UMI Public v0.5 limitations

- Capability is a technical/agentic public profile (chess, software, ML-engineering agent,
  math/science). It is not a broad general-intelligence measure.
- Chess is a narrow puzzle/search signal. WeirdML is ML-engineering agent work, not all
  agentic work.
- Operational Efficiency uses unadjusted mean tokens and steps from the same DeepSWE
  extract. Fast failure can still look cheap.
- Access Economics is one WeirdML cost-per-run column, source-reported, not provider billed.
- Intervals are partial source-interval Monte Carlo, not attempt-level bootstrap.
- Adding a display model does not refit frozen v0.4 panels. v0.5 panels exclude the
  conflicting WeirdML Qwen row by declared policy.
- Preview and High/Max labels are never inferred from a name suffix.
- Grok CursorBench is contamination-risk diagnostic if ever admitted.
- Gemini Preview is a dated service snapshot, not an immutable stable release.
